# Curio — Currency Converter for the curious
**Curio** helps you instantly convert a single amount into multiple currencies while also showing the **Purchasing Power Parity (PPP)** to understand estimated real-world value across different regions.

## Tech Stack
- React (Vite + TypeScript)
- Tailwind CSS
